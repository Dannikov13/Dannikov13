## Featured Project

### Kanban Board

A full-stack Kanban board with drag-and-drop task management and Bunny, an AI planning assistant.

- Create, edit, and organize tasks across columns
- Search, filter, and sort by priority or due date
- Chat with Bunny about current tasks and next steps
- Save tasks and their order in PostgreSQL

- 
- Responsive interface with light and dark themes
- Automated frontend, backend, and Playwright tests
